02 / Protection

Everything ClearURLs did, rebuilt for Manifest V3.

The protections people rely on, running quietly in the background on every request.

  • 2.1

    Removes tracking parameters

    utm_*, fbclid, gclid and hundreds more, from the query and the fragment.

  • 2.2

    Skips redirect middlemen

    Click-through links go straight to their destination, so the tracking hop never happens.

  • 2.3

    Stops search result rewriting

    Google and Yandex can't swap result links for tracked versions when you click.

  • 2.4

    Blocks hyperlink auditing

    Link ping beacons that report your clicks are blocked.

  • 2.5

    Prevents ETag tracking

    Cache validators can't be turned into a persistent identifier.

  • 2.6

    Guards the History API

    Pages can't put tracking back into the address bar with pushState or replaceState.

  • 2.7

    Copies clean links

    A context-menu entry copies any link already cleaned, ready to share.

  • 2.8

    Cleans URLs in bulk

    Paste a list and clean every link at once, without visiting any of them.

  • 2.9

    Blocks tracking domains, optionally

    Complete providers can block known ad and tracking hosts, with a page that still lets you continue.

  • 2.10

    Uncloaks CNAME trackers

    Trackers hiding behind a first-party subdomain are resolved through DNS and matched against the real host.

05 / The standard

CLN 1.0: one rule format, one exact run order.

Clean Link Notation is the JSON format behind built-in, remote and custom rules. The final 1.0 text settles run order, duplicate handling, toggle ids, escaping, redirect safety and what a remote file is allowed to do.

  1. exceptionsSkip the provider if one matches
  2. redirectionsA regex capture or a fixed $redirect= target
  3. fieldRedirectionsA parameter's value becomes the new URL
  4. completeProviderBlock the request outright
  5. rawRulesRegexes on the whole URL, always before field rules
  6. rules · referralMarketingSorted by (stage, orderGroup, order, rank, arrayIndex)
  7. $removeparam filtersLast, guarded by @@ exceptions
Read the standard → Filter syntax 
{
  "cln": "1.0",
  "providers": {
    "amazon": {
      "domainPatterns": ["||amazon.*^"],
      "rawRules": ["\\/ref=[^/?]*"],
      "rules": [
        "qid",
        "$removeparam=/^pd_rd_[a-z]*$/i",
        {
          "id": "token-rewrite",
          "matchPattern": "token",
          "replacePattern": "clean-§1§",
          "order": 5
        }
      ],
      "referralMarketing": ["tag"],
      "exceptions": [
        "||amazon.com^/gp/redirector.html"
      ]
    }
  }
}
DeterministicEvery provider has exactly one run sequence. No order moves a field rule ahead of a raw rule.
Safe redirectsOnly absolute http or https targets, and at most 10 cycles per request.
CapabilitiesRemote files strip, rewrite and except on load; redirect and block wait for your acceptance.
ConformanceWorked examples, lint checks and test vectors define what a conforming engine does.
06 / Privacy

Linkumori collects nothing. No telemetry, no analytics, no usage data. Every URL is cleaned on your device.

Local by default

Built-in rules ship with each release. Nothing is fetched unless you turn remote rules on.

Remote rules are for your own server

Whoever runs an endpoint sees your IP address and when you connect. Use infrastructure you control, or a local network address.

This site too

No third-party fonts, analytics or CDNs; the typeface is served from this site. Read the site's privacy policy.
