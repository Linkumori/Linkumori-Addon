Protection

Quietly cleans everything you load.

Every protection ClearURLs users rely on, rebuilt for Firefox's Manifest V3 and running on every request.

Tracking parameters, gone.

utm_*, fbclid, gclid and hundreds more, removed from the query and the fragment.

No more middlemen.

Click-through redirect links go straight to their destination, so the tracking hop never happens.

Honest search results.

Google and Yandex can't swap result links for tracked versions when you click them.

Cloaked trackers, exposed.

Trackers hiding behind a first-party subdomain are resolved through DNS and matched against the real host.

No ETag or ping tracking.

Cache validators can't become identifiers, and link ping beacons that report your clicks are blocked.

A clean address bar stays clean.

Pages can't put tracking back with pushState or replaceState.

The standard

CLN 1.0. One rule format.
One exact run order.

Clean Link Notation is the JSON format behind built-in, remote and custom rules. The final 1.0 text settles run order, duplicates, toggle ids, escaping, redirect safety and what a remote file may do.

Read the standard Filter syntax reference

Seven stages, in order.

  1. exceptionsSkip the provider if one matches
  2. redirectionsA regex capture or a fixed $redirect= target
  3. fieldRedirectionsA parameter's value becomes the new URL
  4. completeProviderBlock the request outright
  5. rawRulesRegexes on the whole URL, always before field rules
  6. rules · referralMarketingSorted by (stage, orderGroup, order, rank, arrayIndex)
  7. $removeparam filtersLast, guarded by @@ exceptions
JSON
{
  "cln": "1.0",
  "providers": {
    "amazon": {
      "domainPatterns": ["||amazon.*^"],
      "rawRules": ["\\/ref=[^/?]*"],
      "rules": [
        "qid",
        "$removeparam=/^pd_rd_[a-z]*$/i",
        {
          "id": "token-rewrite",
          "matchPattern": "token",
          "replacePattern": "clean-§1§",
          "order": 5
        }
      ],
      "referralMarketing": ["tag"],
      "exceptions": [
        "||amazon.com^/gp/redirector.html"
      ]
    }
  }
}
Deterministic.Every provider has exactly one run sequence. No order moves a field rule ahead of a raw rule.
Safe redirects.Only absolute http or https targets, and at most 10 cycles per request.
Capabilities.Remote files strip, rewrite and except on load. Redirect and block wait for you.
Conformance.Worked examples, lint checks and test vectors define a conforming engine.
