## Section 6 — Remote Rules and Associated Risks

> **Warning:** Enabling Remote Rules exposes your device and network to risks beyond Linkumori's control. Read this Section carefully before enabling this feature.

### 6.1 How Remote Rules Work

The Remote Rules feature is disabled by default. When enabled, the Add-on downloads rule files from URLs specified by the User. The User's browser connects directly to the relevant third-party servers to retrieve these files.

When Remote Rules are disabled, the Add-on operates entirely offline using only its built-in rules, and no external network requests are made by this feature.

### 6.2 Third-Party Data Collection

The relevant third-party servers may collect standard web server information, including, but not limited to:

- IP addresses and geolocation data;
- Browser type, version, and operating system;
- Request timestamps and access logs; and
- Referring URLs and session metadata.

Linkumori does not control, monitor, or store any data transmitted to or collected by these third-party servers.

### 6.3 Disclaimer of Responsibility for Third-Party Servers

Linkumori is not responsible for the privacy practices, data-handling policies, security measures, or conduct of any third-party server from which Remote Rules are retrieved.

The User is strongly advised to review the privacy policy and terms of service of any such third-party server before enabling this feature.

### 6.4 Intended Users

This feature is intended **exclusively for advanced users** who fully understand the associated risks and maintain complete control over their physical and virtual infrastructure, including, without limitation, the servers hosting the rules and the software used to manage server operations.

This feature is **not recommended for general or non-technical users**.

### 6.5 User as Data Controller

Because this feature is intended exclusively for advanced users who maintain full control over their physical and virtual infrastructure, the User is responsible for determining the purposes and means of any data processing carried out through the relevant connection, to the extent provided by applicable law.

The User determines the purpose of using this feature and the intended outcome of connecting to their infrastructure, as well as the manner in which data is collected, handled, and processed within that infrastructure.

Because the User controls both the physical layer (hardware, servers, and network equipment) and the virtual layer (software, operating systems, services, and configurations), decisions concerning that connection rest with the User. The User may choose to log connections, restrict them, disable them entirely, or configure them as they see fit.

Linkumori serves as the instrument through which the User's instructions are carried out. Responsibility for lawful use rests with the User to the extent permitted by applicable law.

### 6.6 User Responsibility When Using Remote Rules

Linkumori is a tool. When the User enables the Remote Rules feature and provides a custom URL, the Add-on executes a fetch request as directed by the User.

Linkumori does not determine, influence, or control which URL the User adds, which server the User connects to, or what data the server provides. These decisions are made by the User.

By providing a URL, the User acknowledges and accepts that:

- It is the **User's responsibility** to ensure that the provided URL complies with all applicable laws in their jurisdiction, including, but not limited to, data protection and privacy laws.
- It is the **User's responsibility** to ensure that they have lawful authority over the physical and virtual infrastructure associated with that URL.
- Linkumori bears no responsibility for the content, legality, or consequences of the URLs the User chooses to add.

### 6.7 Risks of Using Remote Rules

By enabling Remote Rules, the User acknowledges and accepts the following risks:

- **Malicious Rules** — Rule files downloaded from untrusted or compromised servers may contain harmful, deceptive, or unintended instructions that alter the Add-on's behaviour.
- **Data Exposure** — Connecting to external servers may expose the User's IP address, network identity, and device metadata to unknown third parties.
- **Man-in-the-Middle Attacks** — Unencrypted or inadequately secured connections to remote servers may be intercepted, allowing tampered rule files to be delivered to the User's device.
- **Server Compromise** — Even trusted servers may be compromised at any time without notice, potentially causing previously safe rule sources to become dangerous.
- **Loss of Control** — Remote Rules are not verified or audited by Linkumori. The User assumes responsibility for the consequences arising from their use.
- **Legal and Compliance Risks** — Rules retrieved from foreign servers may introduce functionality that violates applicable Indian or local laws. The User is responsible for ensuring compliance with the laws applicable to their use.

### 6.8 Limitation of Liability for Remote Rules

The User enables and uses Remote Rules entirely at their own risk. To the fullest extent permitted by applicable law, Linkumori shall not be liable for any damage, data loss, security breach, legal consequence, or other harm arising directly or indirectly from the use of the Remote Rules feature.

## Section 7 — Issue Reporting Feature

**7.1** The issue reporting feature is an optional, user-initiated tool. Linkumori does not collect, transmit, or store any data through this feature.

**7.2** When the report function is used, the Add-on constructs a GitHub issue URL or GitHub search URL entirely within the User's browser. The Add-on does not transmit any data or contact any server while constructing the URL. No network request is made until the User explicitly chooses to proceed.

**7.3** Before any redirection takes place, the Add-on presents a consent notice and a full preview of the constructed URL in both encoded and human-readable formats. It also gives the User the option to copy the URL, cancel the process, or proceed. No redirection occurs unless the User explicitly confirms their choice.

**7.4** If the User chooses to proceed to GitHub, their interaction with GitHub is governed solely by GitHub's own Privacy Statement and Terms of Service. GitHub may log information such as the User's IP address, browser type, and URL parameters in accordance with its own policies, regardless of whether an issue is ultimately submitted.

**7.5** To the extent that GitHub collects, stores, uses, or otherwise processes personal data, it acts as an independent Data Fiduciary or Data Controller for that processing. GitHub does not process such data on behalf of Linkumori, and Linkumori does not determine GitHub's purposes or means of processing. Linkumori has no access to, and bears no responsibility for, data processed by GitHub once the User's browser navigates to GitHub's website.

**7.6** If the User submits an issue, any information provided, including additional comments, will be publicly visible because the issue is submitted to a public GitHub repository.
