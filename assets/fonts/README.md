The files are unmodified from the npm package. Other subsets (Cyrillic, Vietnamese) are left out because the site doesn't use them. To update, run `npm pack @fontsource/charis-sil`, copy the same eight `.woff2` files from its `files/` folder, and replace `OFL.txt` with the package's `LICENSE`.
