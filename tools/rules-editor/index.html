Rules editor

Linkumori CLN 1.0 · JSON and YAML · runs in your browser

Find providers by name, domain pattern, rule id or entry. Edit one provider or a filtered set, then apply your changes back into the full file. Syntax and the CLN structure are checked as you type. data/linkumori-clearurls.yaml is the source of truth, so edit that file and rebuild the JSON and LZ4 with the CLI. Nothing is uploaded, and your last draft is kept in this browser only.

Load the bundled rules, open a file, or paste one in.
    How to use
    • Load YAML source and Load generated JSON read the files in data/. They only work when this folder is served, for example with python3 -m http.server from the repository root, then http://localhost:8000/tools/rules-editor/. Opened as a file:// page, use Open file… instead.
    • Providers list: click a name to jump to it, or the pencil to edit that provider on its own. Arrow keys move through the list.
    • Filter: plain text ignores case, or tick Regex. Search in limits the match to provider names, domain/URL patterns, rule ids or entries. Add ?q=reddit to the address to start with a filter.
    • Filtered tab: edit only the matching providers, then Apply to full file. Edited providers keep their place, new ones are added and deleted ones are removed. Only matching rules is read-only.
    • Find: press Ctrl/⌘-F in the editor. Enter and Shift-Enter move between matches.
    • Keys: Tab and Shift-Tab indent and outdent. Press Esc, then Tab, to move focus out of the editor.
    • JSON / YAML converts the whole file. YAML output uses the same layout as data/linkumori-clearurls.yaml.
    • The checks here are a quick first pass. Run lint-rules from the CLI before committing.
